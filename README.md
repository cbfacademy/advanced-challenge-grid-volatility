# Grid Volatility Challenge

Welcome to the Grid Volatility Challenge! This repo contains everything you need to get started. 

## The Challenge

You are stepping into the role of a lead data architect and quantitative analyst at an energy trading desk. Your mission is to build a pipeline and decision framwork that helps the desk anticipate weather-driven demand volatility, hedge risk and keep energy moving where it is needed most. 

**Python Version**: This project is pinned to Python 3.12 via .`python-version`. If you use `pyenv` or `uv`, it will be selected automatically. Please do not modify this file unless intentionally updating the project's Python version.

Python 3.12 is the version that most data science libraries have stable compatible wheels for.
